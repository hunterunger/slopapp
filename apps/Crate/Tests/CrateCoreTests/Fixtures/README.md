# Test fixtures

Archives Crate can read but not write, so tests can't generate them:

- `rar.rar`, `rar5_solid.rar`, `rar5_multiarchive.part01-08.rar`, `rar_encryption_data.rar`,
  `rar_encryption_header.rar`: from libarchive's test suite (`libarchive/test/`, tag v3.7.4,
  BSD-2-Clause), decoded from their `.uu` files and renamed without the
  `test_read_format_` prefix.
- `encrypted_data.7z`, `encrypted_header.7z`: a one-file 7z with AES-256 encryption of the
  data, and of data and headers (password `secret`), made with py7zr
  (`SevenZipFile(..., password="secret", header_encryption=...)`).

Everything else (zip, tar, 7z, malicious and broken archives) is generated by the tests.
