# Security

If you find a security problem in any Slopapp app, the launcher or the website, please report
it privately: **[open a private advisory](https://github.com/hunterunger/slopapp/security/advisories/new)**.
Only the maintainers can see it. Please don't open a public issue for it.

Say which app and version, what someone could do with it, and how to make it happen. You'll get
an answer within a week, and credit in the release notes if you'd like it.

Supported: the latest release of each app.
